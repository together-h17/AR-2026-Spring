## 步驟 3：回顧混淆矩陣基本概念

### 核心定義（需熟記）

| 名稱           | 意義                       |
| ------------ | ------------------------ |
| **真陽性 (TP)** | 模型預測為「有變化」，且實際也為「有變化」    |
| **假陽性 (FP)** | 模型預測為「有變化」，但實際為「無變化」（誤報） |
| **真陰性 (TN)** | 模型預測為「無變化」，且實際也為「無變化」    |
| **假陰性 (FN)** | 模型預測為「無變化」，但實際為「有變化」（漏判） |

### 精度指標（需了解公式）

**整體準確率（OA）：** 整體預測正確的比例
$$OA = \frac{TP + TN}{TP + FP + TN + FN}$$

**生產者準確率（PA）：** 實際有變化的像素中，被正確偵測的比例（靈敏度 / 召回率）
$$PA = \frac{TP}{TP + FN}$$

**使用者準確率（UA）：** 被判定為有變化的像素中，實際正確的比例（精確率）
$$UA = \frac{TP}{TP + FP}$$

**Kappa 係數：** 超越隨機機率的一致性
$$\kappa = \frac{OA - p_e}{1 - p_e}$$
其中 $p_e$ 為隨機一致性的期望值。

## 步驟 4：自我測驗 — 手動計算

**情境：** 你對馬太鞍堰塞湖進行變遷偵測，模型與實地驗證結果如下：

```
預測結果      | 變化 | 無變化
---+---+---+---+--------+----------
實際有變化    |   18   |    2
實際無變化    |    1   |   79
```

**請手動計算（不用計算機）：**

1. **TP =** __18___
   **FP =** __1___
   **TN =** __79___
   **FN =** __2___

2. **整體準確率（OA）=**
   $(TP + TN) \div (TP + FP + TN + FN) = $ _(18 + 79)____ $ \div $ _(18 + 1 + 79 + 2)____ $ = $ _(97)____ $ \div $ _(100)____ $ = $ _(97%)____%

3. **生產者準確率（PA）=**
   $TP \div (TP + FN) = $ _(18)____ $ \div $ _(18 + 2)____ $ = $ _(90%)____%
   *(實際變化中，有多少被正確偵測？)*

4. **使用者準確率（UA）=**
   $TP \div (TP + FP) = $ _(18)____ $ \div $ _(18 + 1)____ $ = $ _(94.7%)____%
   *(預測為變化中，有多少是正確的？)*

**答案（完成後再查看）：**

* TP=18, FP=1, TN=79, FN=2
* OA = 97/100 = 97%
* PA = 18/20 = 90%
* UA = 18/19 ≈ 94.7%

**解釋：** 模型在偵測實際變化（PA）與避免誤報（UA）方面表現良好，整體準確率也很高。

## 1️⃣ 為何 PA 不等於 UA？何時偏好哪一個？

**核心差異：分母不同 → 評估角度不同**

- **PA（Producer’s Accuracy）**
= 在「實際有變化」中，被成功抓到的比例
👉 關注「漏判（FN）」
- **UA（User’s Accuracy）**
= 在「被判定為變化」中，真正正確的比例
👉 關注「誤報（FP）」

### 為何不會相等？

因為：

- PA 的分母是 **TP + FN（真實世界）**
- UA 的分母是 **TP + FP（模型輸出）**

👉 模型的錯誤類型（FN vs FP）通常不對稱，所以兩者自然不同。

---

### 何時偏好高 PA？

👉 **不想漏掉變化（寧可多報）**

適用情境：

- 災害監測（堰塞湖、洪水、山崩）
- 疫情/病害偵測
- 早期預警系統

📌 邏輯：
漏掉真正的變化（FN）成本很高

---

### 何時偏好高 UA？

👉 **不想誤報（寧可保守）**

適用情境：

- 政策決策（例如土地違規開發）
- 自動化報告系統
- 精準資源分配（避免浪費）

📌 邏輯：
誤報（FP）會帶來實際成本或錯誤決策

---

## 2️⃣ 光譜混合問題（Spectral Mixing）

### Sentinel-2 一個像素（10m）可能包含：

在堰塞湖情境中，一個像素可能同時包含：

- 水體（清水）
- 泥沙（濁水）
- 裸露土壤（崩塌地）
- 植被（周邊山區）
- 陰影（地形或雲影）

---

### 為何會影響變遷偵測？

1. **光譜訊號被「平均化」**
    - 水 + 土 → 看起來不像純水也不像純土
    - 導致分類模糊
2. **閾值判斷困難**
    - NDWI / NDVI 可能落在「模糊區間」
    - 易造成：
        - FP（誤判為變化）
        - FN（漏掉真實變化）
3. **邊界問題最嚴重**
    - 湖岸、崩塌邊界最容易出錯

👉 **像素不是單一地物，而是混合訊號**

## 3️⃣ 閾值取捨（Threshold Trade-off）

假設你**降低變遷偵測門檻（更容易判定為「變化」）**：

---

### 變化趨勢：

| 指標 | 變化 |
| --- | --- |
| **TP** | ↑ 增加（抓到更多真變化） |
| **FP** | ↑ 增加（誤報變多） |
| **FN** | ↓ 減少（漏判變少） |
| **TN** | ↓ 減少 |

---

### 對 PA / UA 的影響：

- **PA（TP / (TP + FN)）**
    - FN 減少 → **PA ↑ 上升**
    - 👉 更不容易漏判
- **UA（TP / (TP + FP)）**
    - FP 增加 → **UA ↓ 下降**
    - 👉 誤報變多，可信度下降

---

##  整體整理

- 想「不要漏掉」 → 調低門檻 → 高 PA
- 想「不要亂報」 → 調高門檻 → 高 UA
- 光譜混合會讓這個取捨更困難（因為資料本身不乾淨）
