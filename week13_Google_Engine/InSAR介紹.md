可以把它想成：SAR 是用雷達「拍照」，InSAR 是用兩張雷達影像「量地表有沒有移動」。

---

# 一、SAR 是什麼？

**SAR** 全名是 **Synthetic Aperture Radar**，中文常稱為 **合成孔徑雷達**。

一般光學衛星，例如 Sentinel-2，像相機一樣接收太陽光反射，所以會受到：

* 雲
* 雨
* 夜晚
* 陰影
* 煙霧

影響。

但 SAR 不靠太陽光。它是主動式感測器，會自己發射微波雷達訊號到地表，再接收反射回來的訊號。

可以想成：

```text
衛星發出雷達波
↓
雷達波打到地表
↓
地表反射一部分能量回衛星
↓
衛星根據回波強弱形成影像
```

所以 SAR 的優點是：

```text
白天可用
晚上可用
多雲也可用
下雨後仍可能可用
```

這對台灣這種多雲、多雨、山區地形複雜的地方很重要。

---

# 二、SAR 影像到底在看什麼？

SAR 影像不是在看「顏色」，而是在看 **雷達波反射強度**，也就是 **backscatter**。

反射越強，影像上通常越亮。
反射越弱，影像上通常越暗。

## 1. 亮的地方代表什麼？

通常代表雷達波被強烈反射，例如：

* 城市建物
* 粗糙地表
* 森林
* 山坡地
* 岩石裸露區
* 某些幾何角度剛好把雷達波反射回衛星的地方

城市常常很亮，因為建築物牆面和地面會形成類似「角反射器」的效果，把雷達波強烈反射回去。

## 2. 暗的地方代表什麼？

通常代表雷達波反射很弱，例如：

* 平靜水面
* 平滑道路
* 某些平坦裸地
* 雷達波被反射到其他方向、沒有回到衛星的位置

水面常常很暗，因為平靜水面像鏡子一樣，把雷達波反射到別的方向，而不是反射回衛星。

---

# 三、Sentinel-1 SAR 在 GEE 裡可以做什麼？

簡報中提到，Google Earth Engine 裡有完整的 **Sentinel-1 GRD** 影像資料。GRD 是一種已處理好的 SAR 產品，適合做影像分析與時間序列觀察。

在 GEE 中，我們通常可以用 Sentinel-1 做：

```text
1. 看某地區雷達反射強度
2. 做 VV 或 VH 時間序列
3. 比較災害前後變化
4. 建立前後期中值合成影像
5. 匯出 GeoTIFF 給 QGIS 或 Python 使用
```

例如地震前後，我們可以比較山區的 SAR backscatter 是否改變。
如果某些坡面發生崩塌，地表粗糙度、植被覆蓋、水分狀態可能改變，SAR 反射也可能跟著改變。

---

# 四、VV 和 VH 是什麼？

SAR 雷達波有「極化」的概念。可以先簡化理解為：雷達波有不同的振動方向。

Sentinel-1 常用兩種極化：

```text
VV：垂直發射、垂直接收
VH：垂直發射、水平接收
```

不用一開始就背物理細節，可以先這樣理解：

## VV

VV 通常對：

* 地表粗糙度
* 建物結構
* 裸露地
* 水面
* 地形幾何

比較敏感。

## VH

VH 通常對：

* 植被結構
* 森林冠層
* 立體散射
* 複雜地表

比較敏感。

所以在環境監測中，VV 和 VH 可以提供不同角度的資訊。
有時候 VV 對水體、裸地變化很敏感；VH 則更能反映植被結構改變。

---

# 五、SAR 時間序列在看什麼？

如果只有一張 SAR 影像，我們只能知道某一天的狀況。
但如果有很多張 SAR 影像，就可以做 **時間序列分析**。

例如：

```text
2023/01：VV = -8 dB
2023/02：VV = -8.2 dB
2023/03：VV = -8.1 dB
2024/04 地震後：VV = -11 dB
2024/05：VV = -10.5 dB
```

這時候我們就會問：

```text
為什麼地震後 VV 突然下降？
是崩塌？
是土壤濕度改變？
是植被破壞？
是幾何角度影響？
```

也就是說，SAR 時間序列不是只看一張影像，而是看「某個地方的雷達反射是否突然改變」。

---

# 六、為什麼 SAR 需要中值合成？

SAR 影像有一個常見問題：**speckle noise**，中文常譯為斑點雜訊。

你可以把 speckle 想成 SAR 影像中的「鹽巴胡椒雜訊」。
即使地表沒有真的變化，SAR 影像看起來也可能有很多顆粒狀亮暗變化。

所以我們常用多張影像做 **median composite**，也就是中值合成。

概念是：

```text
單張 SAR：雜訊多
多張 SAR 疊起來
每個像元取中值
得到比較穩定的影像
```

中值合成可以降低 speckle 影響，讓真正的地表變化比較容易被看出來。

---

# 七、SAR 和光學影像有什麼不同？

可以用這張表理解：

| 比較項目   | 光學影像，例如 Sentinel-2 | SAR 影像，例如 Sentinel-1 |
| ------ | ------------------ | -------------------- |
| 感測方式   | 被動接收太陽光反射          | 主動發射雷達波              |
| 是否受雲影響 | 很受影響               | 幾乎不受雲影響              |
| 夜晚能不能用 | 不能                 | 可以                   |
| 看的是什麼  | 地表反射的可見光、紅外線       | 雷達回波強度               |
| 常見指標   | NDVI、NDWI、NBR      | VV、VH、backscatter    |
| 適合用途   | 植生、水體、土地覆蓋         | 地表粗糙度、淹水、災害、變形相關分析   |
| 影像直覺性  | 比較像照片              | 較不直覺，需要解讀            |

簡單講：

```text
光學影像像「相機」
SAR 影像像「雷達掃描」
```

---

# 八、InSAR 是什麼？

**InSAR** 全名是 **Interferometric Synthetic Aperture Radar**，中文常稱為 **合成孔徑雷達干涉測量**。

如果 SAR 是用雷達拍照，
那 InSAR 就是拿兩張 SAR 影像來比較它們的「相位差」，進而推估地表有沒有移動。

SAR 訊號其實有兩個重要資訊：

```text
1. Amplitude：回波強度
2. Phase：相位
```

一般 SAR 影像分析多半使用 amplitude，也就是亮暗強度。
InSAR 則使用 phase，也就是雷達波回來時的波形位置。

---

# 九、什麼是相位 Phase？

這裡可以用水波想像。

假設你往水池丟石頭，水波會有：

```text
波峰
波谷
波峰
波谷
```

雷達波也是波。
當衛星發射雷達波到地表再反射回來時，回波會帶有「現在是在波峰還是波谷」的資訊，這就是相位。

如果地表位置稍微改變，雷達波來回距離也會改變，回波相位就會不同。

因此：

```text
地表沒有移動 → 前後兩次相位差小
地表有移動 → 前後兩次相位差變大
```

這就是 InSAR 可以量地表變形的基本原理。

---

# 十、InSAR 可以量什麼？

InSAR 特別適合量測 **地表位移**。

例如：

```text
地震造成的地表抬升或下沉
火山膨脹或收縮
地層下陷
山崩邊坡緩慢滑動
地下水抽取造成的沉陷
工程施工造成的變形
```

它的厲害之處是精度可以到 **公分甚至毫米等級**。
也就是說，地表即使只移動一點點，InSAR 也可能偵測得到。

---

# 十一、InSAR 和一般 SAR 最大差別

可以這樣分：

| 項目       | SAR                    | InSAR          |
| -------- | ---------------------- | -------------- |
| 使用資訊     | Amplitude 回波強度         | Phase 相位差      |
| 主要用途     | 看地表粗糙度、植被、水體、災害變化      | 量地表位移          |
| 結果形式     | SAR 影像、backscatter map | 干涉圖、位移圖、變形時間序列 |
| 資料需求     | GRD 常可使用               | 通常需要 SLC       |
| GEE 是否適合 | 適合                     | 不適合完整 InSAR    |
| 解讀難度     | 中等                     | 較高             |

簡報中特別提到：GEE 裡有 Sentinel-1 GRD，但沒有 Sentinel-1 SLC，因此 **GEE 可以做 SAR amplitude 分析，但不能直接做完整 InSAR phase 分析**。

---

# 十二、為什麼 InSAR 需要 SLC？

SLC 是 **Single Look Complex**。
它保留了完整的複數雷達訊號，也就是包含：

```text
Amplitude 強度
Phase 相位
```

而 GRD 比較像是已經處理成一般影像分析用的產品，主要保留 amplitude 資訊，適合看亮暗、做分類、做變遷偵測，但不適合做精密相位差分析。

所以：

```text
要做一般 SAR 影像分析 → GRD 可以
要做 InSAR 地表變形 → 需要 SLC
```

這也是為什麼簡報說 GEE 裡只能使用 Sentinel-1 GRD，而 InSAR 需要其他工具和資料來源。

---

# 十三、什麼是干涉圖 Interferogram？

InSAR 的核心成果之一是 **干涉圖**。

干涉圖通常會出現彩虹狀條紋，稱為 **fringes**。
這些條紋不是裝飾，而是代表相位變化。

簡報中提到，對 Sentinel-1 來說：

```text
波長 λ 約為 5.6 cm
一個完整 fringe ≈ λ / 2
也就是約 2.8 cm 的地表位移
```

所以如果你在干涉圖中看到 5 個完整 fringe，大致可以估算：

```text
5 × 2.8 cm = 14 cm
```

這代表沿著衛星視線方向可能有約 14 公分的位移。

---

# 十四、為什麼是一個 fringe 等於 λ/2？

這點對初學者容易混淆。

雷達波是從衛星到地表，再從地表回到衛星。
也就是「來回路徑」。

如果地表往衛星方向移動了一點，雷達波的來回總距離會改變兩倍。

因此，對 Sentinel-1 C-band：

```text
波長 λ = 5.6 cm
一個完整相位循環對應到 λ/2 的地表位移
λ/2 = 2.8 cm
```

所以干涉條紋可以用來估算地表移動量。

---

# 十五、如何閱讀一張 InSAR 干涉圖？

可以用四步驟。

## 第一步：看衛星資訊

先確認：

```text
是升軌還是降軌？
是哪個時間段？
是哪兩張 SAR 影像做出來的？
觀測方向是什麼？
```

因為 InSAR 量到的是 **沿衛星視線方向的位移**，不是直接的東西南北或垂直位移。

## 第二步：數條紋

看研究區域內有幾個完整色彩循環。
一個完整彩虹循環就是一個 fringe。

## 第三步：判斷方向

地表是朝衛星移動，還是遠離衛星？
這需要看升軌、降軌、色彩變化方向，以及資料產品的定義。

## 第四步：估算位移

用：

```text
位移 ≈ fringe 數量 × λ/2
```

以 Sentinel-1 為例：

```text
位移 ≈ fringe 數量 × 2.8 cm
```

---

# 十六、InSAR 有哪些限制？

InSAR 很強，但不是萬能。

## 1. 植被太多會降低品質

森林、農地、草地會隨時間改變。
兩張影像之間如果地表散射特性變太多，相位就難以比較，稱為 **decorrelation**。

## 2. 時間間隔太長會失去相干性

如果兩張 SAR 影像間隔太久，地表變化太多，相位可能不穩。

## 3. 大氣會造成誤差

大氣中的水氣會影響雷達波傳播速度，造成看起來像位移的假訊號。

## 4. InSAR 量的是視線方向位移

它不是直接量垂直位移，也不是直接量水平位移，而是量 **Line-of-Sight, LOS** 方向的變化。

## 5. 快速崩塌或劇烈破壞不一定好量

如果地表破壞太嚴重，前後影像完全不相似，InSAR 相位可能無法穩定比較。
這時候反而 SAR amplitude change 或光學變遷偵測可能更有用。

---

# 十七、SAR 與 InSAR 在災害分析中的角色

可以這樣理解：

## SAR 適合回答：

```text
地表粗糙度是否改變？
水體範圍是否變大？
山坡地雷達反射是否突然變化？
災後有沒有出現新的裸露或崩塌區？
雲很多時能不能持續監測？
```

## InSAR 適合回答：

```text
地表有沒有抬升或下沉？
地震造成多少地表變形？
邊坡是否有緩慢滑動？
都市或平原是否有地層下陷？
火山是否正在膨脹？
```

所以兩者不是互相取代，而是互補。

```text
SAR：看地表性質變了沒
InSAR：量地表位置移動了多少
```

---

# 十八、以地震與山崩為例

假設某地發生大地震。

## 用光學影像

可以看：

```text
植被是否消失
NDVI 是否下降
裸露地是否增加
河道是否堵塞
```

但如果震後一直多雲，就很難取得清楚影像。

## 用 SAR amplitude

可以看：

```text
雷達反射是否改變
坡面粗糙度是否變化
水體是否出現
災前災後 backscatter 是否明顯不同
```

即使有雲，也能繼續觀測。

## 用 InSAR

可以量：

```text
地震造成的地表位移
斷層附近的抬升或下沉
山區是否有持續變形
```

但若山崩區破壞太劇烈，InSAR 相位可能失去相干性，這時候就要搭配 SAR amplitude 或光學影像一起判讀。

# 二十、一句話總結

給大學生記憶的版本是：

```text
SAR 是用雷達看地表反射強度，不怕雲、晚上也能看。
InSAR 是比較兩次雷達波相位差，用來量地表有沒有移動，精度可達公分到毫米等級。
```

更簡單地說：

```text
SAR：雷達影像，用來看地表「長什麼樣、變沒變」
InSAR：雷達干涉，用來量地表「移動了多少」
```

在這份簡報的脈絡中，GEE 很適合做 Sentinel-1 SAR 的 VV/VH 時間序列與前後期合成；但若要做真正的 InSAR 地表變形分析，就需要 Sentinel-1 SLC 資料與 SNAP、ISCE2、MintPy、LiCSBAS 等專門工具。
