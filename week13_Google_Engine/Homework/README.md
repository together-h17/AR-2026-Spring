# ARIA v9.0 — The Cloud Engine  
## 秀林／太魯閣植被時序分析報告

**研究區域：** 台灣花蓮秀林／太魯閣地區  
**平台：** Google Earth Engine（GEE）  
**資料來源：** Sentinel‑2 L2A、Sentinel‑1 GRD、SRTM DEM  

---

# 1. 研究目的

將 ARIA 系統從本機端單景分析升級為以 Google Earth Engine（GEE）為核心的雲端多時序分析流程，目的是分析秀林／太魯閣山區的長期植被變化，並評估以下事件造成的環境衝擊：

- 2024/04/03 花蓮地震
- 後續崩塌與堰塞湖相關災害
- 災後植被恢復情形

與前幾週作業（W8–W12）相比，本次分析重點從單一時間點影像，轉變為長時間序列的環境監測。

---

研究區位於台灣東部秀林／太魯閣地區：

TAROKO_BBOX = [

# 3. 資料與分析方法

## 3.1 Sentinel‑2 NDVI 時序分析

### 資料集
- Collection：`COPERNICUS/S2_SR_HARMONIZED`
- 空間解析度：10 公尺
- 時間範圍：2020/01 – 2026/03

### 分析流程

1. 根據：
   - AOI 範圍
   - 日期
   - 雲量比例

   篩選 Sentinel‑2 影像。

2. 使用 Scene Classification Layer（SCL）進行雲遮罩。

3. 計算 NDVI：

```python
NDVI = (B8 - B4) / (B8 + B4)
```

4. 建立每月 median composite。

5. 使用 `reduceRegion()` 計算 AOI 平均 NDVI。

6. 繪製月均 NDVI 時序圖，並標記地震日期。

### 分析目的

NDVI 時序主要用來：
- 觀察植被季節變化
- 偵測地震後植被下降
- 分析長期植被恢復趨勢

---

## 3.2 Composite-based Change Detection

本研究建立三組 NDVI median composite：

| 時期 | 日期範圍 | 用途 |
|---|---|---|
| 震前 | 2023/01 – 2024/03 | 建立基準植被狀態 |
| 震後 | 2024/04 – 2024/09 | 分析地震直接影響 |
| 堰塞湖後期 | 2025/10 – 2026/03 | 分析長期累積變化 |

接著計算三組 ΔNDVI：

```python
delta_eq = post_eq - pre_eq
delta_dam = post_dam - post_eq
delta_total = post_dam - pre_eq
```

其中：
- 負值代表植被減少
- 正值代表植被恢復或增加

本研究使用：

```python
ΔNDVI < -0.15
```

作為顯著植被損失門檻。

---

## 3.3 Sentinel‑1 SAR 時序分析

### 資料集
- Collection：`COPERNICUS/S1_GRD`
- 極化：VV
- 軌道方向：DESCENDING
- 空間解析度：10 公尺

### 分析流程

1. 根據：
   - AOI
   - 日期
   - instrument mode
   - orbit direction
   - VV polarization

   篩選 Sentinel‑1 影像。

2. 計算 AOI 平均 VV backscatter。

3. 建立：
   - VV 時序圖
   - 震前／震後 median composite
   - ΔVV 變化圖

4. 與 NDVI 變化結果交叉比對。

### 分析目的

SAR 分析能補足光學影像的限制，因為雷達訊號可穿透雲層，在山區多雲環境下仍能穩定取得資料。

---

# 4. 分析結果與解讀

## 4.1 NDVI 季節變化

NDVI 時序呈現明顯季節性變化。太魯閣山區整體植被覆蓋率高，但在：
- 梅雨季
- 颱風季
- 冬季

會出現波動。

部分月份因山區長時間雲覆蓋而出現缺值或不穩定結果。

---

## 4.2 地震影響

2024/04/03 地震後，多個區域出現明顯 NDVI 下降。ΔNDVI 圖中可觀察到：
- 崩塌裸露區
- 山坡地裸土
- 河道周邊擾動
- 植被破壞區域

相較於 W9 的雙時相分析，median composite 可有效降低：
- 雲污染
- 單景異常
- 時間差異造成的誤判

因此變遷結果更加穩定。

---

## 4.3 堰塞湖與恢復階段

後期分析顯示：
- 部分區域在次生災害後出現額外植被損失
- 部分地區則開始出現植被恢復現象

三階段比較成功區分了：
1. 地震直接損害
2. 堰塞湖與崩塌次生影響
3. 長期植被恢復

---

## 4.4 SAR 與 NDVI 的關聯

Sentinel‑1 VV 時序在地震後出現明顯 backscatter 變化。

同時具有：
- ΔNDVI 顯著下降
- ΔVV 顯著變化

的區域，可視為高可信度災害區。

多來源分析提高了結果可靠性，因為：
- NDVI 反映植被狀態
- SAR 反映地表粗糙度與含水量變化

兩者結合能降低雲層與暫時性光譜異常造成的不確定性。

# 5. 與前幾週 ARIA 版本比較

| 版本 | 方法 | 限制 |
|---|---|---|
| W8 | 單景 NDVI | 缺乏時間脈絡 |
| W9 | 雙時相 ΔNDVI | 容易受雲與時間差影響 |
| W10 | 單景 SAR | 缺乏長期變化資訊 |
| W12 | 本機 RF 分類 | 本地計算成本高 |
| W13 | GEE 雲端時序分析 | 需依賴雲端平台 |

W13 展示了雲端運算的優勢，包括：
- 同時處理大量影像
- 長期時序分析
- 不需下載全部資料即可完成災害監測

# 7. 限制與討論

雖然 GEE 提供強大的雲端分析能力，但仍有一些限制：

- 匯出速度可能較慢
- 必須依賴網路
- 自訂演算法彈性有限
- 大型 server-side 除錯較困難

而本機端分析（W8–W12）仍適合：
- 自訂機器學習模型
- 離線分析
- 高解析本地資料整合

---

# 8. 結論

本研究展示了 Google Earth Engine 如何將傳統單景遙測分析，轉變為持續性的環境監測系統。

透過 NDVI 與 SAR 時序分析，可以更完整理解：
- 季節性植被變化
- 地震造成的地表擾動
- 次生災害影響
- 災後恢復情形

光學與雷達資料整合，也提高了山區多雲環境下的分析可靠性。

ARIA v9.0 代表從「單張影像解讀」邁向「雲端時序災害監測」的重要升級。
